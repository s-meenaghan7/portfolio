# (Legacy) portfolio site

This repository contains the source code of my legacy website.
The design and original source code of the site is based on a template sourced from html5up.net.

I am rebuilding my website in my [homepage repository](https://github.com/s-meenaghan7/homepage). Once complete, it can be found at the previous domain: https://www.seanmeenaghan.com.

prior to archival:

_I wanted to create a website for myself where I could give visitors a more in-depth overview of who I am that a resume cannot, and links to other social media such as [my LinkedIn](https://linkedin.com/in/seanmeenaghan/) and GitHub. I think having a personal website created from scratch is fitting for any software engineer, even more backend systems-focused engineers such as myself!._

_I was also eager to learn about AWS and cloud-computing in general, and get hands-on with it. Naturally, hosting a website on AWS sounded like a great place to start._

_To achieve both of these goals, I used AWS Amplify to host the website sourced from this repository. I used AWS Route 53 to register an appropriate domain name for my website._
